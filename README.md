# Caffeine 13C NMR Prediction Using Machine Learning
## About
A beginner computational chemistry project
exploring carbon-13 NMR chemical shift
prediction of caffeine.
## Tools Used
-Python
-RDKit
-Scikit-leran
-Matplotlib
## Machine Learning Models
-Random Forest Regression
-Decision Tree Regression
## Project Goals
-Visualize the caffeine molecular in 3D.
-Explore molecular descriptors using RDKit.
-Train regression models for NMR chemical shifts.
-Visualize decision tree predictions.
## Limitations
This is an educational project using a
small dataset of caffeine carbon atoms.
The model has not been validated on unseen molecules.
