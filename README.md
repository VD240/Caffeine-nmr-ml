
☕ Caffeine NMR Analysis and Molecular Fingerprinting

📌 Project Overview

This project explores caffeine molecular analysis using Python and cheminformatics tools. It uses RDKit to process molecular structures, generate molecular fingerprints, calculate molecular similarity, and visualize NMR-related data through 3D surface plots.

The project combines computational chemistry, molecular informatics, and scientific visualization.

🎯 Objectives

- Analyze caffeine molecular structure using RDKit.
- Convert molecular structures into Morgan fingerprints.
- Calculate molecular similarity using the Tanimoto coefficient.
- Explore chemical shift and intensity data.
- Create 3D NMR surface visualizations.
- Develop practical skills in computational chemistry and Python.

🛠️ Technologies Used

- Python
- Jupyter Notebook
- RDKit
- NumPy
- Pandas
- Matplotlib
- Matplotlib 3D Visualization

🔬 Key Features

1. Molecular Structure Processing

Uses RDKit to convert SMILES representations into molecular objects.

2. Molecular Fingerprinting

Generates Morgan fingerprints to represent molecular features as binary vectors.

3. Tanimoto Similarity

Compares molecular fingerprints to calculate structural similarity between molecules.

4. 3D NMR Visualization

Uses Matplotlib to create 3D surface visualizations of chemical shift and intensity data.


⚙️ Installation

Install dependencies:

pip install -r requirements.txt

Install RDKit if it is not included:

pip install rdkit

▶️ How to Run

1. Open the project in VS Code or Jupyter Notebook.
2. Open "caffeine_nmr_analysis.ipynb".
3. Install the required dependencies.
4. Run the notebook cells sequentially.
5. Explore the molecular fingerprints, similarity calculations, and visualizations.
